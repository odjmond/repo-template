## Purpose

This repository is a structural template. When asked to use it, reproduce its folder structure in a separate target repository. Do not develop software in or modify this template repository.

## Copy procedure
1. Obtain the target repository path from the task.
2. Read `README.md` before copying.
3. Use the **Current skeleton structure** section as the default source of truth.
4. Use the **Recommended structure** when the task explicitly requests the full or recommended layout, or to suggest additional folders to create.
5. Create the selected directory structure in the target repository, preserving directory names and nesting.

## Files and exclusions
1. Copy the folder structure only unless the task explicitly requests files.
2. Never copy `.git/` or other repository history.
3. Create empty `AGENTS.md` and `README.md` files in the target repository. Do not copy their contents from this template.
4. Do not copy example initiatives, features, tasks, placeholder files, or sample content unless explicitly requested.

## Target safety
1. Do not overwrite existing files or directories in a non-empty target without explicit approval.
2. Do not initialize Git, install dependencies, select technologies, or create application code unless explicitly requested.
3. Do not modify or delete anything in this source repository.

## Completion
After copying, report:
1. The target path.
2. Which layout was used.
3. Which directories were created.
4. Any requested directories that were skipped or already existed.
